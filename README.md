## About

I write backend code and run the servers it lives on — Python and Kotlin services, a self-hosted homelab, and the occasional side project (and, sure, the occasional Discord bot). My focus is on the parts of a system most people never see, but that keep everything else running: APIs, databases, and the infrastructure underneath them. I'm currently in my final year of German upper-secondary school (Abitur), balancing coursework with independent software projects. Outside of writing code, I spend a fair amount of time on the operational side — deployment, networking, and keeping services alive under real-world constraints.

## Homelab / Self-Hosting

A growing stack of Dockerized services runs behind a self-configured reverse proxy on my own hardware.

- Networking, Linux administration, and troubleshooting under real constraints — no managed platform to fall back on
- Services provisioned, updated, and monitored the same way I'd run anything in production
- A steady testbed for backend work before it touches anything public-facing
